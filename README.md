# Mars & Hope · Figurenschau

Alle dreiundfünfzig Figuren des Epos als gebaute Körper: vier Ansichten je Figur, das Originalblatt
daneben, alle Höhen im echten Größenverhältnis, dazu die Aufnahmen von der Dorfkarte in Unreal.

Seite: https://marsandhope.github.io/figuren/
Die ganze Welt: https://marsandhope.github.io/

Alle Inhalte sind KI-generiert.

Die Dateien hier werden aus dem Projekt „Mars & Hope" erzeugt
(`webseite_figuren/baue_figurenseite.py`). Änderungen von Hand werden beim nächsten Lauf überschrieben.
Die Modelldateien selbst (Blender und FBX, zusammen fast drei Gigabyte) liegen nicht in diesem Repo.
